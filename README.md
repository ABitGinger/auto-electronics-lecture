# 汽车电子控制技术 · 精讲课

面向**零基础**的网页版讲解课：13 讲、98 个讲解段落、约 **50 分钟中文配音**，讲知识点 → 课中 QTE 停下来问一句 → 课末引出题库原题。

**线上版：https://abitginger.top/auto-electronics-lecture/**（手机可直接打开，已做移动端适配）
本地也可以直接双击 `index.html`（用 `python -m http.server` 打开则进度可持久保存）。

---

## 一、它不是题库，是课

| | 内容 |
|---|---|
| 讲 | 13 讲，三章：基础与发动机 / 底盘与整车 / 新能源与智能网联 |
| 讲解段 | 98 段，每段 3~6 分钟一讲，一段一个知识点 |
| 配音 | 98 段中文配音（神经语音），共约 50 分钟 |
| 课中提问（QTE） | 13 个，讲到关键处停下，8 秒倒计时，答错也继续 |
| 课末例题 | 35 个，也就是题库 35 道大题**每题一个**，给答题骨架与评分要点 |
| 期末 | 35 题全考（非抽题）：客观 4 选 1（40 分）+ 主观要点覆盖率（60 分） |

每讲的结构固定：**讲解 3~6 段 → 课中提问 → 继续讲 → 课末例题 → 小结**。所以学习者不需要先看题库，跟着听就行；讲完再看题，题就是刚才那套话。

## 二、操作

| 键 | 作用 |
|---|---|
| `空格` | 暂停 / 继续（配音、字幕、倒计时**一起冻结**） |
| `←` `→` | 上一段 / 下一段 |
| 拖动顶部进度条 | 跳到整门课任意位置（进度＝真实音频位置，连续不跳格） |
| `S` | 本讲讲义（可读、可复制） |
| `C` | 复制本讲为纯文本（含图的文字描述、题目与答案） |
| `M` | 课程目录 |
| `P` / `N` | 语速 / 静音 |
| `1`–`4` | 课中提问时直接选答案 |

暂停页有「复制本讲为文本」：把这一讲的旁白、要点、图意、题目、答案拼成一段纯文本，方便粘给外部 AI 追问。

## 三、时间轴为什么不跳格

整门课只有**一条**时间轴，总长度＝全部 98 段音频时长之和（`data/timing.js`，由 `build/tts_course.py` 生成）。

- 播放时进度条读的是 `audio.currentTime`，所以是连续推进，不是"一步一跳"；
- 拖动时按比例换算成全局时间，再定位到对应段落与该段内的偏移（拖到段尾 1.2 秒内会从该段开头重播，避免"刚点开就跳下一段"）；
- 暂停时禁用 `setTimeout` 计时，倒计时与自动推进都走同一个虚拟时钟，所以暂停后读数完全不动。

## 七、口径说明

- 讲稿面向零基础重写，不复用「题库解析」的写法：先建立概念，再落到题目。
- 题库 35 道大题**每题都在某一讲的课末作为例题出现**，讲义与答案骨架与题库评分要点一致。
- 视频版与网页版共用同一套讲稿与配音，内容完全一致；视频版把 QTE 做成「8 秒倒计时 + 答案卡」。

## 八、移动端与弱网

- **布局**：≤820px 切单列、目录改为浮层、底部只留图标按钮、字幕固定在底部、正文区可滚动；高度用 `100dvh`，避开地址栏伸缩；适配刘海安全区。
- **点击反馈**：所有按钮有按压缩放 + 涟漪，移动端带 7ms 振动；进度条 `touch-action:none`，手指拖动不会误触页面滚动。
- **预加载**：进入某段后自动预取后两段音频；启动页在后台预热第 1、2 段，并在按钮下显示「首段配音已就绪（x.x 秒）」。
- **缓冲提示**：音频 `waiting/stalled` 时右上角出现「缓冲中…」，超过 4.5 秒变「网络较慢，仍在加载…」；`playing/canplay` 自动收起。
- **弱网降级**：音频加载失败时自动改为按估算时长推进文字（不卡死），并提示「本节按文字节奏继续」。
